# Real-Time Weather Forecast & Climate Telemetry App

## Project Description
A responsive weather application that allows users to search for any global city and view real-time weather information along with a 5-day weather forecast.

## Technologies Used
- HTML5
- CSS3 (CSS Flexbox)
- JavaScript
- OpenWeatherMap API
- Fetch API
- Async / Await
- Array.map()

## Features
- Search weather by global city name
- Display current temperature
- Show weather conditions with dynamic icons
- Display humidity
- Show wind speed
- Display atmospheric pressure
- Provide a 5-day weather forecast
- Dynamic background based on weather conditions
- Handle invalid city names and API errors
- Responsive design for mobile devices

## API Used
OpenWeatherMap API

Website: https://openweathermap.org/api

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Configure your OpenWeatherMap API key in the JavaScript file.
4. Open `index.html` in your browser.
