# Personal Portfolio

A modern, responsive personal portfolio website showcasing my profile, technical skills, projects, and development journey as an aspiring software developer.

## Features
- Modern and professional UI
- Responsive design
- Light and Dark mode
- Hamburger navigation
- Home, About, Skills, Projects, and Contact sections
- Project details popup
- Live Demo and GitHub links

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Getting Started
1. Clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
