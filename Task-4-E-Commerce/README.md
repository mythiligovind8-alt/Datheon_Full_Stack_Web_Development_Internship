# E-Commerce Product Catalog & Interactive Shopping Cart

## Project Description
A responsive E-commerce website that fetches product data from FakeStoreAPI and allows users to browse products, search, filter by category, and manage their shopping cart.

## Technologies Used
- HTML5
- CSS3 (CSS Grid)
- JavaScript
- FakeStoreAPI (REST API)
- DOM Manipulation
- JavaScript State Management

## Features
- Fetch products dynamically from FakeStoreAPI
- Display product images, names, prices, and ratings
- Search products by name
- Filter products by category
- Add and remove products from cart
- Increase and decrease product quantities
- Calculate subtotal and total amount
- Interactive shopping cart drawer
- Responsive product grid layout

## API Used
FakeStoreAPI: https://fakestoreapi.com/products

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Expected Outcome
A functional e-commerce storefront with product filtering, cart management, and dynamic product data.
